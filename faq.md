# Часто задаваемые вопросы

## Для чего нужны прокси?

Прокси-сервер позволяет скрыть ваш реальный IP-адрес и заменить его другим. Это предотвращает применение ограничений со стороны сторонних серверов. Основные применения:
- Автоматическая регистрация аккаунтов
- Управление мультиаккаунтами
- Тестирование веб-сервисов
- Сбор данных (парсинг)
- Арбитраж трафика

## Какие типы прокси доступны?

LTEBoost предлагает:
- **Мобильные (4G/5G)** — IP из сотовых сетей, максимальная чистота
- **Резидентные** — реальные IP от интернет-провайдеров
- **Серверные (IPv4/IPv6)** — дата-центровые IP с высокой скоростью

По количеству пользователей мобильные прокси делятся на: Shared (общие), Semi-Private и Private (приватные).

## В чём разница между запросами и соединениями?

В рамках одного соединения можно отправлять несколько запросов. При классической схеме каждый запрос требовал установки нового соединения, что увеличивало нагрузку. Современные протоколы (HTTP/1.1, HTTP/2) поддерживают keep-alive, позволяя переиспользовать соединение.

## Какова политика возврата?

- **До 24 часов**: возврат с комиссией 10%
- **2–7 дней**: возврат с комиссией 15% + вычет стоимости использованного времени
- **После 7 дней**: возврат не производится
- **Краткосрочные тарифы** (1 день, 1 неделя, 2 недели): не подлежат возврату, так как являются платным тестом

## Как настроить прокси в браузере или приложении?

Используйте формат подключения:
```
http://LOGIN:PASSWORD@HOST:PORT
```
или для SOCKS5:
```
socks5://LOGIN:PASSWORD@HOST:PORT
```

Для маршрутизации трафика приложений рекомендуется использовать Proxifier.
