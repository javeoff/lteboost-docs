# LTEBoost — Мобильные прокси для бизнеса

Official Documentation [Website](https://javeoff.docsbook.io/lteboost-docs)

LTEBoost — сервис мобильных и резидентных прокси с 8-летним опытом работы на рынке. Мы предоставляем надёжный доступ к IP-адресам из реальных мобильных сетей и интернет-провайдеров по всему миру.

## Что предлагает LTEBoost

- **Мобильные LTE/5G прокси** — IP из настоящих сотовых сетей, максимальная чистота и ротация по запросу
- **Резидентные прокси** — реальные IP от интернет-провайдеров, оплата только за использованный трафик
- **Серверные прокси** — дата-центровые IP с высокой скоростью и стабильностью

## Быстрый старт

1. Зарегистрируйтесь на [lteboost.com](https://lteboost.com)
2. Выберите тип прокси и оплатите заказ
3. Получите 20-значный код активации
4. Активируйте прокси через Telegram-бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot)

Подробнее — в разделе [Начало работы](начало-работы/README.md).
