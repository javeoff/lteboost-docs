# Резидентные прокси

Резидентные прокси используют IP-адреса от реальных интернет-провайдеров. Такие адреса выглядят как обычные домашние подключения и сложно поддаются обнаружению системами защиты.

## Характеристики

- **Цена**: от $1.2 за ГБ трафика
- **Оплата**: только за фактически использованный трафик
- **Тип IP**: реальные провайдерские IP-адреса
- **Доступность**: множество стран

## Преимущества

- Низкая стоимость по сравнению с мобильными прокси
- Высокий уровень доверия со стороны сайтов
- Подходят для больших объёмов задач
- Широкий выбор геолокаций

## Для каких задач подходят

- **Веб-скрейпинг** — сбор данных с сайтов с умеренной защитой
- **Мониторинг цен** — отслеживание цен конкурентов в e-commerce
- **SEO-задачи** — проверка позиций, парсинг поисковой выдачи
- **Верификация рекламы** — проверка показа рекламы в разных регионах
- **Работа с агрегаторами** — парсинг маркетплейсов и классифайдов

## Сравнение с мобильными прокси

| Критерий | Резидентные | Мобильные |
|---|---|---|
| Цена | Ниже | Выше |
| Чистота IP | Высокая | Максимальная |
| Объём трафика | Неограничен | Зависит от тарифа |
| Лучшее применение | Парсинг, SEO | SMM, арбитраж |
