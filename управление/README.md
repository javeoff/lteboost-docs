# Управление прокси

Все операции с активными прокси выполняются через Telegram-бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot).

## Просмотр активных прокси

1. Откройте бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot)
2. Введите `/start`
3. Выберите **«Мои активные прокси»**
4. Используйте стрелки для навигации между прокси

## Получение данных подключения

В разделе активных прокси для каждого прокси доступны:
- Хост и порт
- Логин и пароль
- Текущий IP-адрес
- Дата истечения

## Смена IP (ротация)

Для ручной смены IP-адреса:
1. Перейдите в **«Мои активные прокси»**
2. Выберите нужный прокси
3. Нажмите кнопку ротации/смены IP

## Форматы прокси

Для подключения в приложениях используйте формат:

```
http://LOGIN:PASSWORD@HOST:PORT
socks5://LOGIN:PASSWORD@HOST:PORT
```

## Настройка в браузере

### Chrome / Firefox (через расширение)
Рекомендуется использовать расширения для управления прокси: Proxy SwitchyOmega (Chrome) или FoxyProxy (Firefox).

### Proxifier
Для маршрутизации трафика конкретных приложений используйте Proxifier. Инструкция по настройке — в [блоге LTEBoost](https://lteboost.com/page/blog).
