# Начало работы

Этот раздел поможет вам быстро начать использовать прокси LTEBoost.

## Шаг 1: Регистрация и выбор прокси

1. Перейдите на [lteboost.com](https://lteboost.com)
2. Выберите подходящий тип прокси (мобильные, резидентные или серверные)
3. Укажите нужную геолокацию и количество трафика

## Шаг 2: Оплата

Поддерживаемые способы оплаты:
- WMZ (WebMoney)
- Robokassa
- Capitalist
- Bitcoin (через Plisio.net)
- PayPal

## Шаг 3: Получение кода активации

После успешной оплаты вы получите **20-значный код активации**. Сохраните его — он потребуется для активации прокси через Telegram-бот.

## Шаг 4: Активация

Активация выполняется через Telegram-бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot).

Подробная инструкция — в разделе [Активация прокси](активация.md).

## Тестирование перед покупкой

Если вы хотите проверить качество прокси до оплаты — воспользуйтесь тестовым доступом. Подробнее — в разделе [Тестирование прокси](тест-прокси.md).
