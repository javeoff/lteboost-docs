# Тестирование прокси

Перед покупкой вы можете получить тестовый доступ к прокси LTEBoost бесплатно.

## Как получить тестовый доступ

1. Откройте Telegram-бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot)
2. Введите команду `/start`
3. В меню выберите **«Получить тестовый доступ»**
4. Следуйте инструкциям бота

## Что проверить при тестировании

После получения тестового прокси рекомендуется проверить:

- **Доступность** — прокси отвечает на запросы
- **Геолокация** — IP соответствует заявленной стране/региону
- **Скорость** — соответствует вашим требованиям
- **Чистота IP** — проверьте через сервисы типа [ipinfo.io](https://ipinfo.io) или [whoer.net](https://whoer.net)
- **Ротация** — при необходимости смените IP через бот

## Инструменты для проверки прокси

| Инструмент | Назначение |
|---|---|
| curl | Базовая проверка доступности |
| Proxifier | Маршрутизация трафика приложений |
| Antidetect браузер | Проверка в браузерной среде |

### Пример проверки через curl

```bash
curl -x http://LOGIN:PASSWORD@HOST:PORT https://ipinfo.io/json
```

Ответ покажет IP-адрес, страну и провайдера прокси.
