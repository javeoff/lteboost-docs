# Активация прокси

После покупки прокси на [lteboost.com](https://lteboost.com) вы получаете 20-значный код активации. Активация выполняется через Telegram-бот.

## Процесс активации

1. Откройте Telegram-бот [@LteBoostMobileBot](https://t.me/LteBoostMobileBot)
2. Введите команду `/start`
3. В появившемся меню выберите **«Активировать прокси»**
4. Введите ваш 20-значный код активации
5. Бот подтвердит успешную активацию и предоставит данные для подключения

## Данные для подключения

После активации вы получите:
- **Хост** (IP-адрес или домен прокси-сервера)
- **Порт**
- **Логин** и **пароль** (для авторизованного доступа)

## Типы прокси по количеству пользователей

| Тип | Описание | Подходит для |
|---|---|---|
| **Shared (Общий)** | Несколько пользователей одновременно | Задач с низкой нагрузкой, бюджетных проектов |
| **Semi-Private** | Максимум 2 пользователя | Баланс цены и чистоты |
| **Private (Приватный)** | Только вы | Важных задач, требующих чистого IP |

## Географическое определение прокси

LTE-прокси привязаны к физическому местоположению SIM-карты. Перед покупкой убедитесь, что нужная вам страна и регион доступны в каталоге на сайте.
