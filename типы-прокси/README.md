# Типы прокси

LTEBoost предлагает три типа прокси, каждый из которых оптимален для определённых задач.

## Сравнение типов

| Параметр | Мобильные LTE/5G | Резидентные | Серверные |
|---|---|---|---|
| Тип IP | Сотовая сеть | Интернет-провайдер | Дата-центр |
| Цена | от $4.8/GB | от $1.2/GB | от $1/GB |
| Чистота IP | Максимальная | Высокая | Средняя |
| Скорость | Высокая | Средняя | Очень высокая |
| Ротация | По запросу | По запросу | По запросу |
| Обнаружение ботами | Минимальное | Низкое | Возможное |

## Когда использовать каждый тип

**Мобильные LTE/5G** — лучший выбор для:
- Управления аккаунтами в социальных сетях
- Арбитража трафика
- Работы с платформами с высокой защитой от ботов
- SMM-задач

**Резидентные** — оптимальны для:
- Веб-скрейпинга и парсинга данных
- Мониторинга цен конкурентов
- SEO-задач
- Задач, требующих большого объёма трафика

**Серверные** — подходят для:
- Высоконагруженных автоматизированных задач
- Парсинга с максимальной скоростью
- Задач, не требующих высокой чистоты IP
